# Icons Directory

Please save the following icon images in this directory:

1. **whatsapp.png** - WhatsApp icon (green)
2. **telegram.png** - Telegram icon (blue)
3. **email.png** - Email/Gmail icon
4. **push.png** - Push notification bell icon
5. **sms.png** - SMS message icon

## Icon Requirements:
- Format: PNG with transparent background
- Size: 512x512px or 1024x1024px (will be scaled down)
- Style: Flat, modern icons matching the app's design
